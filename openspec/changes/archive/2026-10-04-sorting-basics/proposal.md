# Добавить базовые сортировки

## Why

Курс начинается с трёх алгоритмов сортировки, которые хорошо показывают разные способы упорядочить изменяемую последовательность: обмен соседей, вставку в готовую часть и выбор минимума.

## What Changes

- Добавить Bubble Sort, Insertion Sort и Selection Sort для Python 3.15+ и C++26.
- Для каждого алгоритма разместить реализацию и тесты в соответствующих деревьях языков.
- Добавить одну страницу Sphinx с кодом, краткой идеей, корректностью, устойчивостью и сложностью алгоритмов.
- Добавить новую capability `sorting-algorithms` с контрактами этих трёх реализаций.

## Non-goals

- Другие алгоритмы сортировки, структуры данных и новые языки.
- Внешние библиотеки тестирования для C++.
- Benchmark-наборы и оптимизации сверх учебных реализаций.

## Decisions

- Python API работает на месте с изменяемой последовательностью, принимает keyword-only `key` и `reverse`, и возвращает `None`. Результат `key` вычисляется один раз для каждого элемента.
- C++ API предоставляет перегрузку для пары итератор/ sentinel и перегрузку для range; range-перегрузка делегирует итераторной. Сортировка принимает `comp` и `proj`.
- Bubble Sort и Insertion Sort сохраняют относительный порядок равных элементов; Selection Sort не обещает устойчивость.
- В каждой реализации основной алгоритм остаётся цельным; отдельные файлы/функции добавляются только для публичного фасада или общей логики.

## Risks

- Сборка C++26 с `import std;` требует достаточно новой версии Clang и поддерживаемой сборки CMake. Проверки будут запущены доступным toolchain; ограничения окружения будут указаны отдельно.
