## Context

Пользователь выбрал «И реализации, и оформление — как в design-patterns». Проверены актуальные web/index.html, settings/{panel,preferences,schema,storage,vscode}.js, themes/catalog.json и code_viewer. Референс содержит реальные переключатели, не только палитру.

## Decisions

- Переиспользовать независимые settings/themes/decorate компоненты и шрифты с лицензиями. Ключ localStorage отдельный для algorithms, чтобы курсы не перезаписывали настройки друг друга.
- Сохранить Sphinx: обычный материал остаётся доступен без JS; панель и рабочая область подключаются ES-модулем. Ошибка загрузки не скрывает материал.
- HTML page context собирает полные исходники literalinclude и локальные зависимости из src с детерминированной подсветкой. Передача JSON экранирует HTML-значимые символы.
- Код выбирается явными селекторами: файл/реализация и сравнение со вторым файлом. URL сохраняет выбор. Два столбца выравниваются по строкам; номера, маркеры и diff не входят в копируемый исходник. На узком экране видна одна выбираемая сторона.
- Режимы и настройки доступны с клавиатуры. Панель на мобильном удерживает фокус и закрывается Escape. Идентификаторы/селекторы адаптируются к Sphinx, вместо переноса SPA целиком.
- Тема задаёт одновременно оболочку и подсветку. Локальные шрифты, варианты начертаний и импорт VS Code соответствуют референсу. Перенос скрывает номера строк. Настройки diff и синхронной прокрутки применяются к сравнению.
- Исправление идёт отдельным коммитом после уже опубликованного курса, затем отдельным коммитом сохраняются результаты deployment и OpenSpec.
