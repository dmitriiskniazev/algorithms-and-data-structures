## Context

Утверждён выбор: только minimum/maximum в обоих семействах. Каждый контейнер хранит один экстремум.

## Decisions

- stack.extrema/{minimum,maximum}.py содержит Stack[T:Comparable] с push/pop/peek/extreme и __len__. Общая запись value/extreme находится в _types.py.
- queue.extrema/{minimum,maximum}.py содержит Queue с двумя экземплярами соответствующего стека, переиспользуя хранение и обновление экстремума. Перенос выделен в _transfer.
- Обе версии сравнивают только <; максимум меняет порядок аргументов. Для эквивалентных значений конкретный объект экстремума не фиксируется.
- ExtremaStack и ExtremaQueue расширяют свои обычные интерфейсы методом extreme. Старые имена удаляются.
- Случайные проверки сравнивают поведение с list/deque и min/max, объект с единственным __lt__ проверяет отсутствие дополнительных требований.
