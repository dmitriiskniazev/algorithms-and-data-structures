## Why

Пользователь просит яснее отделить код от текста и сделать оформление единым. При выключенных «Изменениях» просмотрщик сейчас только скрывает подсветку, сохраняя искусственные строки выравнивания.

## What Changes

- Выделить код общими панелями с границей, отдельным фоном/заголовком и одинаковыми кнопками в Разборе и Коде; добавить умеренные разделители разделов.
- Без «Изменений» рендерить каждый файл собственными исходными строками; только diff использует строки выравнивания.
- При переключении сохранять выбранные файлы, сторону мобильного сравнения, фокус и прокрутку; копирование остаётся точным.
- Проверить оба режима и опубликовать исправление GitHub Pages.

## Capabilities

### New Capabilities
Нет.

### Modified Capabilities
- documentation-site: различимость кода и исходные строки без режима изменений.

## Impact

Общие стили, заголовки/копирование листингов, просмотрщик, генерация палитр и web-тесты. Учебные алгоритмы и структура курса не меняются.
