## Context

Текущий model.align создаёт общий список строк с null-пробелами. view.refresh меняет только data-changes, поэтому выключение diff не удаляет пробелы. Фон кода совпадает с фоном страницы, а заголовки и копирование оформлены разными компонентами.

## Decisions

- Модель выдаёт отдельные наборы строк для каждой стороны. При diff они используют общее выравнивание, без diff — исходные индексы файлов, включая только настоящие пустые строки.
- refresh перестраивает только содержимое панелей при смене diff; селекторы, заголовки, фокус, текущая мобильная сторона и прокрутка сохраняются.
- Общий source.css задаёт фон, границу, поля и заголовок для literalinclude, примеров, раскрываемого кода и рабочего пространства. Удаляются дублирующие стили из course.css и адаптера reader.
- Палитры генерируют code-surface/code-header; различимость не зависит только от оттенка: остаётся видимая граница и отступы. Печатное оформление светлое.
- Листинги Разбора используют тот же clipboard helper и кнопку copy-button. Для literalinclude кнопка находится в подписи, для длинного кода — в summary без переключения details при копировании, для простых примеров создаётся заголовок.
- Исходники остаются неизменными; UI не удаляет настоящие пустые строки. Настройки и варианты файлов продолжают работать во всех темах.

## Verification

Регрессия на разных длинах файлов и настоящих пустых строках; Node/DOM переключение diff туда/обратно с проверкой числа строк/номеров, исходника/копии и мобильной стороны. Общая сборка/check и проверка опубликованного SHA. Доступность реального браузера проверяется отдельно, DOM не считается визуальной приёмкой.
