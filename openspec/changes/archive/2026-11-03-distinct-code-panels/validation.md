# Проверка разделителей кода и независимых строк

## Реализация

Общий reader/source.css задаёт панели, рамки, поля, фон и заголовки кода в Разборе и Коде. Стили заголовков и кнопок убраны из конкурирующих компонентов. Исходники с подписями, обычные примеры и раскрываемые листинги используют copy-button и один clipboard helper. Копирование в summary отменяет стандартное действие, не раскрывая/сворачивая исходник. Небольшие разделители добавлены между разделами, inline-код отделён фоном.

Для 22 палитр генерируются отдельные code-surface/code-header, отличные от page. Граница остаётся дополнительным признаком отделения. Печатная палитра светлая.

Без Изменений displayRows создаёт собственные индексы каждого файла, без null/искусственных строк. Настоящие пустые строки остаются строками исходника. С diff используется выравнивание. При переключении перестраиваются только тела панелей; селекторы, фокус, сторона и позиции прокрутки сохраняются.

## Проверки
