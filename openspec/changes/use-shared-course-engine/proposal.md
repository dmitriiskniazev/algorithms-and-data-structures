# Proposal

## Why

Курс поддерживает копии ресурсов интерфейса соседнего курса. Подключение одного пакета позволит получать общие исправления через явное обновление зависимости.

## What Changes

- Подключить course-engine 0.1.0 из GitHub с полным SHA в группе docs, зафиксировать uv.lock и убрать временный vendor-wheel.
- Копировать общие ресурсы из установленного пакета только в результат сборки; удалить проверенные исходные дубликаты после резервной копии и успешной сборки с пакетом.
- Сохранить Sphinx, Markdown, формулы, literalinclude и выбор произвольной пары исходников; настройки и команды курса остаются совместимыми.

## Capabilities

### New Capabilities

- `shared-course-assets`: воспроизводимая сборка общего интерфейса из установленного пакета без соседнего checkout.

### Modified Capabilities

Нет. Пользовательские требования существующего интерфейса сохраняются.

## Impact

Адаптер сборки, локальные UI-модули, темы/шрифты, pyproject.toml, uv.lock, тесты и инструкции. Учебный код и содержание не меняются. Удалённая публикация и чужие changes вне области.
