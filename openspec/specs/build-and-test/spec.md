# Build and Test Specification

## Purpose

Фиксирует общую настройку Python-среды и команды сборки и проверок для учебных примеров на Python.

## Requirements

### Requirement: Python-среда управляется uv

Корневые pyproject.toml и uv.lock SHALL описывать устанавливаемый проект Python 3.15+ с backend uv_build. uv sync SHALL устанавливать проект из src/ в корневое окружение .venv в editable-режиме. Импорты algorithms и data_structures SHALL работать без PYTHONPATH и настройки pytest pythonpath.

#### Scenario: Настраивается Python-среда
- **WHEN** участник запускает make setup под Python 3.15 или новее
- **THEN** uv синхронизирует зависимости, устанавливает проект, а pytest обнаруживает тесты под tests/

#### Scenario: Более старая версия Python отклоняется
- **WHEN** участник пытается использовать Python ниже 3.15
- **THEN** конфигурация сообщает о несоответствии версии

#### Scenario: Импорт не зависит от рабочего каталога
- **WHEN** установленный проект импортируется из другого каталога без PYTHONPATH
- **THEN** доступны algorithms и data_structures с прежними именами публичных функций и классов

### Requirement: Документация собирается только в HTML

Результаты сборки документации SHALL иметь только формат HTML и находиться в игнорируемом `docs/_build/html/`. Инструкции SHALL указывать `make docs` и актуальный путь сайта, а исходники документов SHALL оставаться вне каталога сборки. Репозиторий SHALL NOT содержать отдельный PDF-образец или команду его сборки.

#### Scenario: Собран сайт
- **WHEN** участник запускает `make docs`
- **THEN** сайт создаётся в `docs/_build/html/` без PDF-файлов и без обращения к TeX Live

### Requirement: Команды курса используют Python

Курс SHALL использовать только Python 3.15+ для учебных реализаций. Корневой Makefile SHALL предоставлять setup через uv sync, test/test-python через uv run pytest и docs через строгую HTML-сборку Sphinx. Установка компилятора и настройка внешней системы сборки SHALL NOT требоваться.

#### Scenario: Запущен полный набор проверок
- **WHEN** участник запускает make test
- **THEN** выполняются Python-тесты из tests/ через uv

#### Scenario: Реализаций и тестов пока нет
- **WHEN** участник запускает make test без Python-тестов
- **THEN** команда завершается успешно и сообщает об отсутствии тестов

### Requirement: Очистка Python-курса сохраняет окружение

make clean SHALL удалять docs/_build, dist, корневые .cache, .pytest_cache, .ruff_cache и __pycache__ под src/ и tests/. Команда SHALL сохранять исходники, документацию, OpenSpec, .venv и индекс CodeGraph и SHALL успешно выполняться повторно.

#### Scenario: Очищены результаты сборки и тестов
- **WHEN** участник запускает make clean после make test и make docs
- **THEN** перечисленные сборочные файлы и кеши отсутствуют, окружение и рабочие материалы сохранены

#### Scenario: Очистка повторяется
- **WHEN** участник повторно запускает make clean
- **THEN** команда завершается успешно без создания окружения или сборочных файлов

### Requirement: Python-исходники проходят статические проверки

Dev-зависимости uv SHALL включать Ruff и Pyright. Команды проекта SHALL проверять все src/ через Ruff и строгую проверку типов Pyright, без исключения проблемных модулей. Подавления проверок некорректных типов SHALL отсутствовать; отдельные стилистические диагностики SHALL настраиваться явно и обоснованно. Приёмка SHALL включать полный pytest и строгую HTML-сборку.

#### Scenario: Запущена статическая проверка
- **WHEN** участник запускает документированную команду проверки
- **THEN** проверяются все исходники и типовые примеры вызовов, а нарушение аннотаций приводит к ненулевому коду возврата

### Requirement: Проверки не пропускаются из-за отсутствия средства поиска

Make test SHALL запускать pytest, когда в tests есть test_*.py, и SHALL NOT зависеть от наличия ripgrep. При отсутствии тестов команда SHALL сообщать об этом и завершаться успешно. Публикация SHALL опираться на фактическую сводку pytest, а не только успешный статус оболочки.

#### Scenario: Runner без rg
- **WHEN** tests содержит тесты, а rg не установлен
- **THEN** make test выполняет pytest и возвращает его код завершения

#### Scenario: Тестов нет
- **WHEN** tests отсутствует или не содержит test_*.py
- **THEN** команда сообщает об отсутствии тестов и завершается успешно
