# Min/max стек и очередь с выбранным экстремумом

## Задача

Добавьте запрос одного выбранного экстремума за O(1), сохранив обычный порядок извлечения стека или очереди.

:::{container} task-facts

**Вход.** Добавления 3, 1, 4 в minimum-стек и minimum-очередь.

**Результат.** Оба extreme() возвращают 1; pop() стека возвращает 4, очереди — 3.

:::

**Предусловия.** `<` задаёт строгий слабый порядок; минимум/максимум выбирается модулем, а не аргументом.

### Проверка

Запустите пример: утверждения фиксируют ожидаемое поведение.

```python
from data_structures import queue, stack

s = stack.extrema.minimum.Stack[int]()
q = queue.extrema.minimum.Queue[int]()
for value in [3, 1, 4]:
    s.push(value)
    q.push(value)
assert s.extreme() == q.extreme() == 1
assert s.pop() == 4
assert q.pop() == 3
```


## Один экстремум в стеке

Для minimum храним минимум каждого префикса, для maximum — максимум. Новый push сравнивает значение с прежним экстремумом. После pop открывается запись предыдущей глубины с уже готовым ответом.

**Инвариант.** В записи глубины $i$ хранится экстремум значений $s_0,\ldots,s_i$. База — единственный элемент; push вычисляет экстремум прежнего префикса и нового значения, pop возвращает предыдущий префикс. Повторяющиеся значения сохраняют тот же инвариант.

## Очередь из двух соответствующих стеков

Оба варианта очереди используют два экземпляра своего варианта стека. incoming принимает значения; при пустом outgoing процедура `_transfer` переворачивает порядок. Поэтому pop возвращает голову FIFO. extreme выбирает экстремум двух непустых стеков, обращаясь к их готовым ответам.

**Корректность.** Два стека разделяют все значения очереди, поэтому экстремум очереди равен экстремуму их экстремумов. При переносе префиксы outgoing строятся заново через push и сохраняют инвариант стека. Каждое значение переносится не более одного раза до удаления.

## Симметричные варианты

| Семейство | Минимум | Максимум | Запрос |
|---|---|---|---|
| Стек | `stack.extrema.minimum.Stack` | `stack.extrema.maximum.Stack` | `extreme()` |
| Очередь | `queue.extrema.minimum.Queue` | `queue.extrema.maximum.Queue` | `extreme()` |

Каждый контейнер хранит один экстремум. Значения сравниваются только через `<`; максимум меняет местами аргументы сравнения. При эквивалентных значениях конкретный возвращаемый объект не фиксируется. На пустом контейнере pop/peek/extreme вызывают IndexError.

| Структура | Обновление | extreme | Активная память |
|---|---|---|---|
| Стек | амортизированное $O(1)$ | $O(1)$ | $O(n)$ |
| Очередь | амортизированное $O(1)$; перенос $O(n)$ | $O(1)$ | $O(n)$ |

Массивы могут удерживать историческую ёмкость. Монотонная очередь скользящего окна хранит только кандидатов; здесь сохраняются все значения.
