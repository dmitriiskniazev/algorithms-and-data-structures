# Очередь и дек

## Задача

Сохраните FIFO очереди и дополните его операциями с обоих концов дека.

:::{container} task-facts

**Вход.** Добавления 1 и 2 в очередь.

**Результат.** Извлечения 1 и 2 независимо от внутреннего переноса.

:::

**Предусловия.** Пустой доступ вызывает IndexError; динамическое хранение может выделять новый буфер.

### Проверка

Запустите пример: утверждения фиксируют ожидаемое поведение.

```python
from data_structures.queue import two_stacks

queue = two_stacks.Queue[int]()
queue.push(1)
queue.push(2)
assert [queue.pop(), queue.pop()] == [1, 2]
```

## Контракт

Очередь: push добавляет в хвост, peek смотрит голову, pop извлекает голову. Дек: push_front/push_back добавляют на выбранном конце; front/back смотрят, pop_front/pop_back извлекают. Все поддерживают размер и пустоту. Пустой доступ вызывает IndexError.

## Идеи и инварианты

Кольцевая очередь хранит голову `first` и число элементов `_size`; физический индекс логического элемента i — `(first+i) % capacity`. При заполнении буфер удваивается, элементы копируются/перемещаются в логическом FIFO-порядке и голова становится нулевой. Удалённая ячейка очищается, ёмкость не сокращается. Память O(max n) по максимальному числу одновременно хранимых элементов, а не обязательно O(текущего n).

Связный дек хранит первое/последнее звено и соседние ссылки. При удалении последнего элемента обе границы становятся пустыми. Из него получаем связанную очередь, используя только push_back/pop_front. Python разрывает обратные связи удалённых узлов.

Очередь через два стека: incoming принимает новые элементы, outgoing выдаёт старые. Если outgoing пуст, весь incoming переворачивается в outgoing. Только такой перенос сохраняет FIFO. Каждый элемент проходит через перенос один раз, что даёт амортизированную гарантию.

| Версия | Добавление | Извлечение / просмотр |
|---|---|---|
| ring.Queue | амортизированное O(1), рост O(n) | O(1) |
| linked_list.Queue | O(1) | O(1) |
| two_stacks.Queue | амортизированное O(1) | амортизированное O(1); перенос O(n) |
| deque.Deque | O(1) с любого конца | O(1) с любого конца |

Рабочая память O(n), кроме удерживаемой кольцевой ёмкости и ёмкости массивов стеков, зависящих от исторического максимума. Дек реализован явно через связанные узлы; стандартный deque используется только как тестовый эталон. Тесты чередуют операции, переходят через границу кольца, увеличивают ёмкость и сверяют FIFO/оба конца с эталоном.

 Копирование кольцевого контейнера запрещено.
