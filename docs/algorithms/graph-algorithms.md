# Продвинутые алгоритмы на графах

## Задача

Найдите кратчайшие пути или минимальный остов, выбирая алгоритм по ограничениям графа.

:::{container} task-facts

**Вход.** Дуги 0→1 веса 2, 0→2 веса 5, 1→2 веса 1.

**Результат.** Расстояния от 0: (0, 2, 3).

:::

**Предусловия.** Для примера Дейкстры все веса $w(e)\ge0$; ограничения других алгоритмов указаны ниже.

### Проверка

Запустите пример: утверждения фиксируют ожидаемое поведение.

```python
from algorithms.graphs import dijkstra

graph = [[(1, 2), (2, 5)], [(2, 1)], []]
dist, parent = dijkstra.shortest_paths(graph, 0)
assert dist == (0, 2, 3)
assert parent == (None, 0, 1)
```

Пусть ориентированный граф задан списком смежности на вершинах `0..V-1`. Для взвешенных графов запись `(v, w)` означает дугу в `v` веса `w`; для остовного леса ребро записывается как `(w, u, v)`. Реализации используют целые веса. Prim принимает неориентированный граф со списком смежности, в котором каждая копия ребра представлена с обеих сторон.

Список смежности хранит `V` списков и `E` записей дуг: он занимает `Θ(V+E)`, позволяет перечислить соседей `u` за `Θ(deg(u))` и хорошо подходит для разреженных графов. Матрица смежности занимает `Θ(V²)`, проверка наличия дуги занимает `Θ(1)`, а перебор всех соседей вершины — `Θ(V)`; она удобна для плотных графов и алгоритмов вроде Floyd–Warshall, работающих со всеми парами. Для неориентированного графа каждое ребро в списке записывается у обоих концов, а матрица симметрична. Выбор представления входит в оценку: одна и та же операция по списку и матрице может иметь разную стоимость.

## Косарайю: компоненты сильной связности

```{literalinclude} ../../src/algorithms/graphs/strongly_connected_components.py
:language: python
:pyobject: find
```

Вершины `u` и `v` принадлежат одной компоненте сильной связности (КСС), если достижимы друг из друга. КСС — классы эквивалентности этого отношения, а сжатие каждой КСС в одну вершину превращает граф в DAG.

Первый итеративный DFS сохраняет вершину при выходе, после просмотра всех исходящих дуг. Затем строится транспонированный граф, и по нему запускается DFS в обратном порядке выхода. Почему вторая фаза не пересекает границу компоненты? Рассмотрим DAG компонент и дугу `C → D`. В первом обходе, если `C` посещена раньше `D`, то `D` завершится раньше `C`; если раньше посещена `D`, путь обхода не может попасть обратно в `C`, иначе это были бы одна КСС. В обоих случаях `finish(C) > finish(D)`. Поэтому следующей максимальной меткой среди ещё не обработанных компонент обладает источник DAG; в транспонированном DAG из него не выходит дуга в другую ещё не обработанную компоненту. DFS второй фазы выделяет ровно одну КСС. Индукция по компонентам доказывает полноту разбиения.

Каждая вершина и дуга просматривается O(1) раз в обеих фазах. Время — `O(V+E)`, память — `O(V+E)` на транспонированный граф, отметки и стеки. Обе фазы итеративны, поэтому глубина графа не ограничена стеком вызовов.

## Кратчайшие пути

Оба алгоритма возвращают пару массивов: расстояния от источника и предшественники. `None` означает недостижимую вершину; у источника предшественник также отсутствует. Восстановление пути — последовательное следование предшественникам до источника с последующим обращением последовательности.

### Алгоритм Дейкстры

```{literalinclude} ../../src/algorithms/graphs/dijkstra.py
:language: python
:pyobject: shortest_paths
```

Алгоритм требует `w(e) ≥ 0` для каждой дуги и проверяет это условие до вычисления. Индексируемая бинарная min-heap хранит не более одной записи на вершину; массив позиций позволяет уменьшать ключ при улучшении расстояния. Поэтому одна вершина извлекается не более одного раза, а устаревших записей нет.

**Инвариант жадного извлечения.** Когда из очереди впервые извлекается актуальная запись вершины `v` с расстоянием `d[v]`, это расстояние оптимально. Предположим обратное и возьмём кратчайший путь в `v`; пусть `x` — первая на нём ещё не извлечённая вершина, а `y` — её уже извлечённый предшественник. При обработке `y` релаксация дуги `y → x` установила оценку не больше длины префикса кратчайшего пути до `x`. Все веса неотрицательны, поэтому префикс до `x` не длиннее полного пути до `v`. Значит, в очереди была бы запись не больше `d[v]`, противоречащая тому, что извлечено `v`. Следовательно, фиксация корректна. После фиксации релаксация всех исходящих дуг обеспечивает корректные оценки соседей; по индукции все достижимые вершины обрабатываются с оптимальными расстояниями.

С каждой дугой связано не более одного уменьшения ключа; вставка, уменьшение и извлечение стоят `O(log V)`. Время — `O((V+E) log V)`, память — `O(V)`, включая очередь, позиции и массивы результата. Вход и граф не меняются.

### Алгоритм Беллмана—Форда

```{literalinclude} ../../src/algorithms/graphs/bellman_ford.py
:language: python
:pyobject: shortest_paths
```

Релаксация дуги `u → v` заменяет `d[v]` на `min(d[v], d[u]+w(u,v))`, только если `u` уже достижима. После `i` полных проходов все кратчайшие пути, содержащие не более `i` дуг, учтены: база — путь длины ноль в источнике; на шаге `i` последняя дуга любого такого пути релаксируется из правильного префикса длины не более `i-1`. Если достижимого отрицательного цикла нет, кратчайший путь можно выбрать простым, следовательно, он содержит не более `V-1` дуг. Ещё один проход обнаруживает улучшаемую достижимую дугу тогда и только тогда, когда существует достижимый отрицательный цикл. Недостижимый отрицательный цикл ответа не портит.

Время — `O(VE)`, память — `O(V+E)` включая явный список дуг; ранняя остановка не меняет худшую оценку. Достижимый отрицательный цикл приводит к `ValueError` вместо фиктивных конечных расстояний.

## Минимальный остовный лес: Краскал и DSU

```{literalinclude} ../../src/algorithms/graphs/kruskal.py
:language: python
:pyobject: minimum_spanning_forest
```

Остовный лес содержит остов каждой компоненты связности исходного неориентированного графа. Сортируем рёбра по неубыванию веса и добавляем ребро, только если оно соединяет разные компоненты DSU. Петля всегда отбрасывается; параллельные рёбра корректны, потому что после первого соединяющего ребра следующие образуют цикл.

**Теорема безопасного ребра.** Пусть `A` — уже выбранный лес, а `e` — минимальное по весу ребро, пересекающее разрез, согласованный с `A` (никакое ребро `A` не пересекает этот разрез). Тогда существует минимальный остов, содержащий `A ∪ {e}`. Возьмём оптимальный остов `T`, содержащий `A`. Если `e` уже лежит в `T`, утверждение доказано. Иначе добавление `e` создаёт цикл; на цикле есть ребро `f`, пересекающее тот же разрез. Оно не лежит в `A`. Из минимальности `e` следует `w(e) ≤ w(f)`, поэтому замена `f` на `e` не увеличивает вес и сохраняет остов. Индукция по добавляемым рёбрам доказывает оптимальность леса Краскала; равные веса могут давать разные, но одинаково оптимальные леса.

DSU хранит компоненты как корневые деревья, сжимает путь в `find` и присоединяет меньшее дерево к большему. Высота до сжатия не превосходит `O(log V)`: при каждом увеличении глубины размер содержащего корня множества как минимум удваивается. Совместное применение сжатия пути и объединения по размеру даёт амортизированное `O(α(V))` на операцию, где `α` — обратная функция Аккермана. Сортировка доминирует: `O(E log E)` времени; DSU занимает `O(V)`, сортируемый список рёбер — `O(E)` памяти.

## DAG-кратчайшие пути

```{literalinclude} ../../src/algorithms/graphs/directed_acyclic_shortest_paths.py
:language: python
:pyobject: shortest_paths
```

Топологически упорядочим вершины и релаксируем исходящие дуги в этом порядке. Отрицательные веса допустимы: в DAG нет циклов, а значит, нельзя бесконечно уменьшать расстояние обходом цикла. Перед обработкой вершины все возможные предшественники уже обработаны, поэтому её расстояние окончательно. Время `O(V+E)`, память `O(V)` сверх входа.

## Floyd–Warshall: все пары

```{literalinclude} ../../src/algorithms/graphs/floyd_warshall.py
:language: python
:pyobject: shortest_paths
```

Матрица `D⁽⁰⁾` задаёт веса дуг, нули на диагонали и отсутствие дуги как `None`. На итерации `k` разрешаем использовать вершины `0..k-1` внутри пути:

`D⁽ᵏ⁺¹⁾[i,j] = min(D⁽ᵏ⁾[i,j], D⁽ᵏ⁾[i,k] + D⁽ᵏ⁾[k,j])`,

пропуская сумму, если одно из слагаемых недостижимо. Любой путь либо не проходит через `k`, либо распадается в `k` на два пути с уже разрешёнными внутренними вершинами — это доказывает переход индукцией. После всех `V` фаз получены кратчайшие расстояния. Отрицательное значение на диагонали означает достижимый отрицательный цикл; алгоритм сообщает об ошибке. Время `Θ(V³)`, память `Θ(V²)`.

## Prim: остовный лес

```{literalinclude} ../../src/algorithms/graphs/prim.py
:language: python
:pyobject: minimum_spanning_forest
```

Prim поддерживает множество уже добавленных вершин одной компоненты и для каждой внешней вершины хранит вес самого дешёвого соединяющего ребра. Каждый шаг берёт минимум таких кандидатов. Если очередь опустела, текущая связная компонента завершена; запуск из следующей ещё не добавленной вершины формирует лес и сохраняет изоляты.

Корректность следует из свойства безопасного ребра: граница между уже добавленными вершинами и остальными задаёт разрез, не пересекаемый выбранными ранее рёбрами. Минимальное пересекающее ребро можно включить в некоторый оптимальный остов заменой ребра на цикле. Значит, каждый шаг сохраняет возможность продолжить до оптимального остова. Индексируемая очередь хранит не более одной записи на вершину, поэтому время `O((V+E) log V)`, дополнительная память `O(V)`.

## Сравнение моделей

| Алгоритм | Допущения | Время | Дополнительная память |
|---|---|---:|---:|
| DAG-кратчайшие пути | DAG, веса произвольного знака | `O(V+E)` | `O(V)` |
| Дейкстра | неотрицательные веса, список смежности | `O((V+E) log V)` | `O(V)` с индексируемой кучей |
| Беллман—Форд | произвольные веса, нет достижимого отрицательного цикла | `O(VE)` | `O(V+E)` |
| Floyd–Warshall | матрица, нет отрицательного цикла | `O(V³)` | `O(V²)` |
| Краскал | неориентированный взвешенный граф | `O(E log E)` | `O(V+E)` |
| Prim | неориентированный взвешенный граф, список смежности | `O((V+E) log V)` | `O(V)` |
