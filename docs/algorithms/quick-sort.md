# Рандомизированная быстрая сортировка

## Задача

Отсортируйте последовательность, каждый раз разделяя её вокруг опорного значения на три группы.

:::{container} task-facts

**Вход.** [3, 1, 2, 1].

**Результат.** [1, 1, 2, 3]; повторяющиеся значения образуют общую группу.

:::

**Предусловия.** `<` задаёт строгий слабый порядок; $[left,right)$ — корректный рабочий полуинтервал.

## Контракт

Сортировка переставляет входную последовательность. Функция возвращает `None`; для воспроизводимости можно передать `rng=random.Random(...)`. Значения сравниваются напрямую через `<`, задающий строгий слабый порядок. Пустой вход допустим. Равные ключи могут менять относительный порядок.

## Идея и корректность

Случайно выбираем pivot и разделяем полуинтервал `[left,right)` на три части: строго меньше pivot по выбранному порядку, эквивалентные pivot и строго больше. Эквивалентность определяется двумя сравнениями, поэтому не требуется `==` у payload. Группа равных занимает `[equal_left, equal_right)` внутри рабочего `[left, right)`. После разбиения сортируем только крайние части; средняя уже на окончательных местах. Индукция по длине этих частей даёт корректность всей сортировки.

Опорное значение сохраняется до перестановок. Процедура `_sort(values, left, right, rng)` получает всё состояние рекурсии явно.

## Варианты и сложность

| Версия | Что показывает | Время | Дополнительная память |
|---|---|---|---|
| Рекурсивная базовая | Два прямых рекурсивных вызова | ожидаемое O(n log n), худшее O(n²) | ожидаемо O(log n), худшее O(n) стека |
| Итеративная, улучшение памяти | Большую часть откладываем, меньшую обрабатываем сразу | те же гарантии | O(log n) явного стека в худшем случае |
| Трёхстороннее разбиение, улучшение на повторах | Исключаем весь блок равных ключей | O(n) для одинаковых ключей | O(1) на одно разбиение |

Обе версии используют трёхстороннее разбиение. Все сравнения используют исходные значения. Рандомизация не исключает худший случай; универсальной «оптимальной» версии здесь не заявляем. Рекурсивная версия может превысить лимит рекурсии Python на неудачном входе. Для воспроизводимости передавайте генератор с фиксированным seed.

Тесты: `tests/algorithms/sorting/quick_sort/` — случайные входы, повторы и записи с единственным оператором `<`.

Предусловия partition: границы задают корректный конечный полуинтервал, pivot принадлежит ему; `<` задаёт строгий слабый порядок значений. Операция возвращает границы блока эквивалентных pivot.
