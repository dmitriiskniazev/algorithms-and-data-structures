# Разделяй и властвуй

## Задача

Разделите вход на меньшие задачи и объедините ответы. На примере инверсий посчитайте пары, нарушающие порядок.

:::{container} task-facts

**Вход.** [3, 1, 2]

**Результат.** Две инверсии: пары позиций (0, 1) и (0, 2); вход не меняется.

:::

**Предусловия.** Для инверсий $i<j$ и $a_j<a_i$; условия геометрической задачи приведены в её разделе.

### Проверка

Запустите пример: утверждения фиксируют ожидаемое поведение.

```python
from algorithms.divide_and_conquer import inversions

values = [3, 1, 2]
assert inversions.count(values) == 2
assert values == [3, 1, 2]
```

Метод **«разделяй и властвуй»** строит решение рекурсивно: разбивает задачу на подзадачи, решает их, объединяет результаты. Для доказательства обычно используют индукцию по размеру входа; для анализа времени — рекуррентность. Здесь `n` — длина диапазона.

## Бинарный поиск

Бинарный поиск на каждом шаге продолжает работу только в одной половине диапазона. Его [отдельный урок](binary-search.md) содержит постановку задач lower_bound/upper_bound, итеративные и рекурсивные реализации, доказательства и производные операции. Исходники относятся к категории `algorithms.searching`.

## Merge Sort

Разделяем диапазон пополам, рекурсивно сортируем обе части и сливаем их. При слиянии сравниваем первые невыбранные элементы двух отсортированных частей. Если они равны, выбираем элемент слева: это сохраняет исходный взаимный порядок равных ключей, то есть сортировка устойчива.

**Корректность по индукции.** Для длины 0 или 1 диапазон уже отсортирован. Для `n≥2` половины меньше `n`, поэтому по предположению индукции они отсортированы. На каждом шаге слияния в выход помещается наименьший из оставшихся элементов; следовательно, выход остаётся упорядоченным и содержит ровно все элементы обеих половин. Выбор слева при равенстве сохраняет устойчивость.

Каждый уровень рекурсии обрабатывает `Θ(n)` элементов, глубина дерева — `Θ(log n)`. Поэтому

```text
T(n) = 2T(⌊n/2⌋) + Θ(n) = Θ(n log n),
```

а вспомогательный буфер занимает `Θ(n)` памяти. Это сортировка исходного диапазона с дополнительным линейным буфером, не сортировка с константной дополнительной памятью. Процедура `_sort` управляет рекурсией, `_merge` сливает две отсортированные половины.

## Подсчёт инверсий

Инверсия — пара позиций `i<j`, для которой `a[i]>a[j]`. Прямой перебор требует `Θ(n²)` сравнений. Слияние позволяет посчитать их за `Θ(n log n)`: если при слиянии текущий правый элемент строго меньше текущего левого, то он меньше каждого из ещё не выбранных элементов левой половины. Добавляем к ответу число оставшихся элементов слева. При равенстве выбираем левый элемент и не добавляем инверсию, так что определение остаётся строгим.

После рекурсивного подсчёта внутри половин и подсчёта переходящих через середину пар получаем

```text
I(n) = I(⌊n/2⌋) + I(⌈n/2⌉) + I_cross(n),
```

где слияние вычисляет `I_cross` за линейное время. Итоговая оценка — `Θ(n log n)` времени и `Θ(n)` памяти. Алгоритм сортирует внутреннюю копию и не меняет вход.

## Ближайшая пара точек

На вход подаются целочисленные точки `(x, y)` с координатами в `[-10⁹, 10⁹]`. Результат содержит два различных исходных индекса и квадрат расстояния; для нуля или одной точки возвращается отсутствие пары. Возвращаемая пара минимизирует
`(xᵢ − xⱼ)² + (yᵢ − yⱼ)²`. Ограничение координат позволяет без переполнения вычислять квадрат расстояния в знаковом 64-битном целом: максимум равен `8·10¹⁸ < 2⁶³−1`.

```{literalinclude} ../../src/algorithms/divide_and_conquer/closest_pair.py
:language: python
```

Сначала сортируем точки по `(x, y, исходный индекс)` и за линейный проход после сортировки ищем совпадающие координаты. Такая пара имеет расстояние ноль и сразу оптимальна. Эта проверка нужна и для доказательства полосы: при множественных совпадениях невозможно ограничить число точек в геометрической ячейке положительным минимальным расстоянием.

Рекурсия работает с непрерывным отрезком x-массива. Его середина задаёт разделение **по рангам**, а не условием `x < separator`: при равных x это гарантирует, что каждая точка попадает ровно в одну половину. Вместе с каждым элементом y-массива хранится ранг в x-массиве, поэтому y-последовательность фильтруется по принадлежности половине за линейное время. Разделительная координата фиксируется до рекурсивного вызова; точки с `x = separator` могут оказаться с обеих сторон, но обе стороны всё равно лежат по разные стороны прямой `x = separator` (граница общая).

Каждая половина возвращает только свою ближайшую пару. Входной y-массив уже отсортирован, а фильтрация сохраняет порядок, поэтому повторное слияние не нужно: полосу строим прямо из входного массива. Пусть `δ` — меньшее расстояние, найденное в половинах. Улучшающая пара должна лежать в полосе `|x − separator| ≤ δ`; иначе её горизонтальный разнос сам по себе не меньше `δ`. В полосе просматриваем точки по возрастанию y и сравниваем текущую точку не более чем с семью следующими, прекращая просмотр, когда разность y превышает `δ`.

Почему достаточно семи? Для каждой стороны от разделителя рассмотрим прямоугольник ширины `δ` и высоты `δ` над текущей точкой. Разобьём его на четыре квадрата со стороной `δ/2`. Диагональ каждого такого квадрата равна `δ/√2 < δ`, поэтому в нём не может быть двух точек одной половины: это противоречило бы определению `δ`. Значит, в прямоугольнике не более четырёх точек слева и четырёх справа. Сама текущая точка занимает одну из восьми возможных позиций, так что впереди не более семи кандидатов. Равенство `x = separator` можно отнести к любой стороне в этом рассуждении: разбиение по рангам уже гарантировало уникальную принадлежность, а геометрическая оценка использует только расстояния внутри каждой половины.

Сортировка и предварительный поиск дубликатов требуют `O(n log n)`. На каждом уровне рекурсии фильтрация и просмотр полосы суммарно занимают `O(n)`, поэтому `T(n)=2T(n/2)+O(n)=O(n log n)`. Копии y-массивов на одном уровне суммарно имеют длину `O(n)`; глубина рекурсии `O(log n)`, а вспомогательная память с учётом рекурсии — `O(n)`.

## Где применять

- Бинарный поиск требует упорядоченной последовательности и быстрого доступа по индексу; для связного списка его логарифмическое число сравнений не означает логарифмическое время доступа.
- Merge Sort гарантирует `Θ(n log n)` и устойчивость, платя буфером `Θ(n)`.
- Подсчёт инверсий иллюстрирует общий приём: рекурсивно решить подзадачи и аккуратно посчитать элементы, пересекающие их границу.
- Ближайшая пара демонстрирует, почему важно сохранять вспомогательный порядок между уровнями рекурсии: повторная сортировка по y внутри каждого узла дала бы `O(n log² n)`, а стабильная фильтрация исходного y-порядка сохраняет `O(n log n)`.

Для следующего шага полезно сравнить эти алгоритмы с геометрическими задачами, где кандидаты на объединение нельзя ограничить константой.
