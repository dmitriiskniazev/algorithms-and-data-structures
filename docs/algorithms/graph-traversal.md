# Обходы графа и первые структурные свойства

## Задача

Обойдите вершины графа и найдите расстояния от источника по числу рёбер. Затем используйте обход для свойств графа.

:::{container} task-facts

**Вход.** Цепочка 0—1—2, источник 0.

**Результат.** Расстояния (0, 1, 2), предшественники (None, 0, 1).

:::

**Предусловия.** Вершины пронумерованы $0,\ldots,n-1$; источник существует.

### Проверка

Запустите пример: утверждения фиксируют ожидаемое поведение.

```python
from algorithms.graphs import breadth_first_search

graph = [[1], [0, 2], [1]]
assert breadth_first_search.traverse(graph, 0) == ((0, 1, 2), (None, 0, 1))
```

## Модель графа

Пусть `G = (V, E)`, `V = {0, …, n−1}`. В программе граф задаётся списком смежности `adj`: элемент `adj[u]` перечисляет вершины `v`, для которых есть дуга `u → v`. Неориентированное ребро `{u,v}` хранится дважды: `v` в `adj[u]` и `u` в `adj[v]`. Петли и параллельные рёбра разрешены; для алгоритмов неориентированного графа число вхождений `v` в `adj[u]` должно совпадать с числом вхождений `u` в `adj[v]`.

Обозначим через `V` число вершин, через `E` — число дуг ориентированного графа или число рёбер неориентированного графа. Размер списка смежности равен `Θ(V+E)` (для неориентированного графа каждое ребро занимает две записи). Поэтому список смежности особенно удобен для разреженных графов. Все реализации используют явный стек или очередь: глубина обхода не ограничена стеком вызовов языка.

## BFS: расстояния по числу рёбер

Поиск в ширину (`breadth-first search`, BFS) обрабатывает вершины слоями: сначала источник `s`, затем все вершины на расстоянии 1, затем на расстоянии 2 и так далее. Для каждого обнаруженного `v` хранятся `dist[v]` и `parent[v]`; источник имеет расстояние 0 и не имеет предшественника, недостижимые вершины имеют `None` в обоих полях.

```{literalinclude} ../../src/algorithms/graphs/breadth_first_search.py
:language: python
:pyobject: traverse
:caption: src/algorithms/graphs/breadth_first_search.py
```

```text
BFS(adj, s):
  dist[*] ← ∞; parent[*] ← None
  dist[s] ← 0; Q ← очередь [s]
  пока Q не пуста:
    u ← Q.pop_front()
    для v из adj[u]:
      если dist[v] = ∞:
        dist[v] ← dist[u] + 1; parent[v] ← u
        Q.push_back(v)
  вернуть dist, parent
```

**Корректность.** Инвариант очереди: расстояния в ней не убывают. Вершина помещается в очередь только при первом обнаружении, а обнаруженная из `u` вершина получает расстояние `dist[u]+1`. Индукцией по числу снятий с очереди все вершины с расстоянием `k` извлекаются прежде вершин с расстоянием `k+1`. Если кратчайший путь до `v` имеет длину `k>0`, его предпоследняя вершина `u` имеет расстояние `k−1`; при обработке `u` алгоритм обнаружит `v` и назначит ему `k`. Более короткое значение невозможно: оно потребовало бы пути короче кратчайшего. Значит, `dist[v]` равно кратчайшему числу рёбер, а `parent[v]` задаёт один такой путь.

Каждая вершина ставится в очередь не более одного раза, а каждый список смежности просматривается один раз: время `O(V+E)`, память `O(V)`. В невзвешенном графе это кратчайшие пути по числу рёбер, но не по сумме произвольных весов.

## DFS: углубление вдоль пути

Поиск в глубину (`depth-first search`, DFS) продолжает текущий путь, пока можно открыть непосещённого соседа, затем возвращается к предыдущему выбору. Стек кадров `(вершина, позиция следующего соседа)` имитирует рекурсивный обход и сохраняет порядок первого посещения. Сосед помечается до помещения кадра в стек — поэтому сходящиеся ветви не добавляют вершину повторно.

```{literalinclude} ../../src/algorithms/graphs/depth_first_search.py
:language: python
:pyobject: traverse
:caption: src/algorithms/graphs/depth_first_search.py
```

```text
DFS(adj, s):
  пометить s; вывести s; стек ← [(s, 0)]
  пока стек не пуст:
    (u, i) ← вершина стека
    если i = degree(u): снять кадр
    иначе:
      увеличить i в верхнем кадре
      v ← adj[u][i]
      если v не помечена: пометить, вывести и добавить (v, 0)
```

**Корректность.** Вершина выводится только в момент перехода из непосещённого состояния, значит, повторов нет. Кадр остаётся на вершине до просмотра всех её соседей; каждый непосещённый сосед открывается немедленно. Следовательно, после завершения нет ребра из посещённой области в непосещённую достижимую вершину. Все и только вершины, достижимые из `s`, посещены. Каждый кадр создаётся один раз и каждое ребро просматривается один раз: `O(V+E)` времени и `O(V)` памяти.

## Компоненты связности

Для неориентированного графа повторный обход из каждой ещё не посещённой вершины выделяет одну компоненту. Внутренний обход посещает ровно её: достижимость замкнута относительно рёбер, и любая вершина компоненты достижима по определению. Внешний цикл гарантирует, что будут включены и изолированные вершины, а отметка посещения исключает пересечение компонент. В итоге получаем разбиение `V`; суммарное время `O(V+E)`, дополнительная память `O(V)`.

## Двудольность и нечётные циклы

Граф двудолен, если вершины можно раскрасить в два цвета так, чтобы концы каждого ребра имели разные цвета. Обход в ширину назначает источнику цвет 0, а каждому впервые встреченному соседу — противоположный. Если уже раскрашенное ребро соединяет равные цвета, алгоритм возвращает `false`.

```{literalinclude} ../../src/algorithms/graphs/bipartite.py
:language: python
:pyobject: check
:caption: src/algorithms/graphs/bipartite.py
```

**Теорема.** Неориентированный граф двудолен тогда и только тогда, когда в нём нет цикла нечётной длины.

Если есть корректная двухцветная раскраска, цвета вдоль любого цикла чередуются; чтобы вернуться в начальный цвет, число рёбер должно быть чётным. Обратно, в каждой компоненте выберем корень и раскрасим вершину по чётности расстояния от него. Если ребро соединяет одинаковые цвета, два дерева кратчайших путей от корня вместе с этим ребром образуют нечётный замкнутый обход; из него можно удалить повторяющиеся участки, пока не останется нечётный цикл. Значит, при отсутствии нечётных циклов конфликт невозможен и раскраска корректна. Петля сама является нечётным циклом длины 1. Проверка выполняется за `O(V+E)` времени и `O(V)` памяти.

## Обнаружение циклов

В неориентированном DFS ребро к уже посещённой вершине означает цикл, если это не то единственное вхождение ребра, по которому пришли в текущую вершину. Нужно пропустить ровно одно вхождение родительского ребра: второе параллельное ребро уже образует цикл длины 2, а петля сразу ведёт в посещённую вершину. Список кадров хранит флаг пропуска. Это даёт `O(V+E)` времени и `O(V)` памяти.

Для ориентированного DFS вершины имеют состояния: белая (не открыта), серая (на текущем стеке) и чёрная (все дуги просмотрены). Дуга в серую вершину замыкает ориентированный цикл. Дуга в чёрную вершину цикла не доказывает: обе вершины уже завершили обход и могут лишь сходиться к одной вершине. Каждый узел и каждую дугу обрабатываем ограниченное число раз, то есть `O(V+E)` времени и `O(V)` памяти.

## Топологическая сортировка

Топологический порядок ориентированного графа — перестановка вершин, где для каждой дуги `u → v` вершина `u` стоит раньше `v`. Такой порядок существует ровно у DAG (ориентированных ациклических графов). DFS добавляет вершину в список завершения только после обработки всех её исходящих дуг; ответ — обратный порядок завершения.

```{literalinclude} ../../src/algorithms/graphs/topological_sort.py
:language: python
:pyobject: sort
:caption: src/algorithms/graphs/topological_sort.py
```

**Корректность.** Рассмотрим дугу `u → v`. Если `v` белая, DFS завершит `v` до `u`. Если `v` чёрная, она уже завершена до `u`. Серая `v` означала бы обратную дугу и цикл, поэтому для DAG такой случай невозможен. Следовательно, для каждой дуги `v` завершается раньше `u`, и при обращении списка `u` оказывается раньше `v`. Все компоненты запускаются отдельно, поэтому порядок содержит также несвязанные и изолированные вершины. Цикл обнаруживается той же серой дугой и приводит к ошибке вместо ложного порядка. Время `O(V+E)`, память `O(V)`.

| Задача | Тип графа | Время | Дополнительная память |
|---|---|---:|---:|
| BFS из `s` | ориентированный или неориентированный | `O(V+E)` | `O(V)` |
| DFS из `s` | ориентированный или неориентированный | `O(V+E)` | `O(V)` |
| Компоненты связности | неориентированный | `O(V+E)` | `O(V)` |
| Двудольность | неориентированный | `O(V+E)` | `O(V)` |
| Цикл | ориентированный или неориентированный | `O(V+E)` | `O(V)` |
| Топологическая сортировка | ориентированный | `O(V+E)` | `O(V)` |
